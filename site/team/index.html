The room name and password never leave this page. The room address is a hash of it, and the coordinates are decrypted locally with a key derived from it — the relay only ever handles ciphertext, exactly as the mod does.

This page only listens. It sends nothing, so it never appears as a player, and it can only show frames broadcast while it is open — the relay stores no history.

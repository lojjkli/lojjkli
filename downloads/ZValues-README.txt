ZValues
=======
A trade value calculator for Murder Mystery 2 (Roblox).
Made by lojjkli - https://lojjkli.site


DO I NEED PYTHON OR ANYTHING ELSE INSTALLED?
---------------------------------------------
No. ZValues.exe is a single, self-contained file. Just double-click it -
nothing else to install, nothing else to download.


WINDOWS SAYS "WINDOWS PROTECTED YOUR PC" - IS THAT SAFE?
---------------------------------------------------------
Yes. That warning shows up because this .exe isn't signed with a paid
code-signing certificate (those cost money each year; this is a free hobby
project) - it isn't a sign that anything is actually wrong with the file.

To get past it:
  1. Click "More info"
  2. Click "Run anyway"

This usually only shows up the first time you run it.


HOW DO I USE IT?
-----------------
When you open ZValues.exe, a small console window appears while it loads
current values in the background. Once it says "Ready", you get two options:

  Use Program    - opens ZValues in its own window
  Use on Browser - opens it in your normal web browser instead

Both work the same way - pick whichever you prefer. You can close the
console window's tools later; closing it also closes ZValues itself, so
leave it running in the background while you use the calculator.


WHERE DO THE VALUES COME FROM?
--------------------------------
ZValues reads current values from third-party MM2 value-list sites. Those
are community estimates, not guaranteed prices - they can be wrong, out of
date, or briefly unreachable. Use your own judgment before trading; ZValues
is a tool to help you decide, not a guarantee of what a trade is worth.


TROUBLESHOOTING
------------------
Nothing loading / stuck on "Loading values..."?
  Check your internet connection, then close and reopen ZValues.

Windows Defender or antivirus flags it?
  Same root cause as the SmartScreen warning above - it's unsigned, not
  unsafe. If you'd rather verify it yourself before running it, the source
  is available on request - see Support below.
